完成通知推送到手机
一轮对话跑完时把结果推到手机 —— 人不在电脑前也能知道它跑完了。
走的是现成的免费推送服务，扩展直接把消息发过去，不经过任何第三方中转，也不收集账号信息。
ntfy · 安卓 / iPhone Bark · 仅 iPhone 自定义 Webhook
ntfy.sh 和 Bark 是现成的免费推送服务，手机上装个 App 拿个地址就行；Webhook 用你已有的机器人地址。都不用注册，也不用自己搭服务器。
手机装 ntfy（App Store / Google Play / F-Droid 都有）→ 点「订阅 topic」→ 填同一个字符串。
topic 相当于密码，起个别人猜不到的；公共服务器上知道 topic 的人就能收到消息。
用别的 ntfy 服务器（大多数人不用管）
留空就用公共的 ntfy.sh，不用自己搭任何东西。只有你另外部署了 ntfy 服务端，才需要在这里填你的地址。
iPhone 装 Bark → 首页复制那串 key 粘进来，不用注册。
飞书：群里点「设置」→「群机器人」→「添加机器人」→「自定义机器人」→ 复制 Webhook 地址粘到这里。
企业微信：群机器人同理，地址形如 qyapi.weixin.qq.com/cgi-bin/webhook/send?key=…。
其他能收 JSON POST 的地址（Server 酱、自建转发）也能用，按域名自动匹配消息格式。
飞书机器人默认不校验签名，留空即可。如果你在机器人设置里勾了「签名校验」，把这串密钥填进来，扩展会自动算 timestamp + sign。
积分口径
消耗只认平台真实扣减（余额差分 / 消息里的结算值），不做任何 Token 折算估算。
抓不到积分的数据会显示为 0，不会去猜一个数。
